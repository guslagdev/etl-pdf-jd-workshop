# ETL de Extração de Dados de um PDF

Este projeto realiza um processo de ETL (Extração, Transformação e Carga) para obter dados a partir de arquivos PDF.

---

## 🛠️ Tecnologias Utilizadas

* **Python**

---

## 🚀 Como Rodar

(Insira aqui os comandos para instalar as dependências e executar o projeto. Ex: `pip install -r requirements.txt` e `python main.py`)

---

## Steps seguido:

Passo 1: Instalando as bibliotecas ✅ \
Passo 2: Criando a estrutura do projeto para ler os PDFs (Extract) ✅ \
Passo 3: Agrupando as informações do PDF e enviando para o Banco de Dados ⌛ \
Passo 4: Transformando os dados com - https://www.getdbt.com/ ⌛ \
Passo 5: Construindo o dashboard com - https://streamlit.io/ ⌛
